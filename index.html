Tres minitalleres de IA en el navegador

HTML y JavaScript para explorar necesidades de accesibilidad y apoyo a personas cuidadoras.

  1. OCR: de imagen a texto
  2. Audio: de voz a texto
  3. Gestos: cambiar una tarjeta con la mano

Aprende paso a paso

Cada taller incluye la demostración, una guía explicada, ejercicios y el código completo. Puedes consultar todo desde esta web.

  • Guía de OCR · Ejercicios de OCR
  • Guía de transcripción · Ejercicios de transcripción
  • Guía de gestos · Ejercicios de gestos

Necesitas conexión para descargar las librerías y los modelos. Las imágenes, el audio y el vídeo se procesan en este navegador; estos ejemplos no los envían a un servidor.

En la web publicada puedes entrar directamente en cada taller. Permite el acceso a la cámara o al micrófono cuando quieras utilizarlos. La primera carga del modelo puede tardar.

Si descargas el código para modificarlo, ábrelo con Live Server o un servidor local, no haciendo doble clic en el HTML.

Guía completa, ejercicios y código en GitHub.
