Tres minitalleres de IA en el navegador

HTML y JavaScript para explorar necesidades de accesibilidad y apoyo a personas cuidadoras.

  1. OCR: de imagen a texto
  2. Audio: de voz a texto
  3. Gestos: cambiar una tarjeta con la mano

Necesitas conexión para descargar las librerías y los modelos. Las imágenes, el audio y el vídeo se procesan en este navegador; estos ejemplos no los envían a un servidor.

Abre el proyecto mediante Live Server o un servidor local, no haciendo doble clic en el HTML. Cámara y micrófono necesitan localhost o HTTPS.

Guía completa, ejercicios y código en GitHub.
